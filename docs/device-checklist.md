# 设备验证清单（每个里程碑发版前执行一轮）

CI 只证明「构建得出、测试过」；本清单证明「真机好用」。发版前在下面每一行打勾并记录日期与设备，
结果追加到该版本 CHANGELOG 节尾（如「已过设备清单 2026-11-05，Pixel 5 / API 35」）。任何一项失败即阻塞发版。

## 环境

- 至少一台 arm64 真机（主力机优先），一台 Android TV（模拟器可接受）
- 网络环境：可直连的 Wi-Fi、一个可用订阅/节点、移动数据（可选）

## 安装与升级

- [ ] 新装：首次启动直达 Flutter 界面，无旧 Fragment 残影；VPN 授权弹窗正常
- [ ] 覆盖升级：从上一个已发布版本直接安装，数据（订阅/配置/设置/收藏）完整保留
- [ ] 跨大版本升级路径演练（仅里程碑大版本时）：备份 → 卸装 → 新装 → 恢复

## 核心

- [ ] 连接/断开/切换节点各三次，无崩溃；通知栏按钮切换生效
- [ ] TUN 模式下第三方应用真实走代理（浏览器打开 IP 查询）
- [ ] 分应用代理：排除/包含名单生效
- [ ] 切换 rule/global/direct 三模式各自生效
- [ ] 断网重连：飞行模式开关后自动恢复或一键重连成功

## 状态卡与探针

- [ ] 出口 IP/国家/组织显示正确；国旗与点击切码正常；长按刷新生效
- [ ] IP 质量区块在缓存未命中（新 IP）时能取到质量数据（v3.0.11 探针修复回归点）
- [ ] 探针进行中切走/取消，无崩溃、无残留错误提示

## 订阅与节点

- [ ] 导入订阅（URL/剪贴板/二维码）各一次成功
- [ ] 手动更新订阅 + 到期自动更新（观察一次即可）产生变更报告
- [ ] 节点 typed 表单新建/编辑/删除（至少覆盖 Shadowsocks、VLESS、Hysteria2 三协议）
- [ ] 批量测速面板：进度、直方图、连最快

## 日志与导出

- [ ] 日志页三级（核心/Logcat）可过滤、暂停、清屏、导出；取消保存对话框无任何提示（v3.0.12 回归点）
- [ ] 导出的 .log 不含订阅凭据（抽查 URL/uuid 字段已被脱敏）

## TV

- [ ] D-pad 焦点在主页/代理/设置页可循环移动，焦点环可见且不被卡片遮挡（shape_badge 回归点）
- [ ] 通知/遥控上一台/下一台切换服务器

## 备份

- [ ] 导出 .thrbackup → 恢复到另一台设备（或同机卸装后），收藏/设置/订阅完整
- [ ] WebDAV 上传 + 恢复一次

## 自更新

- [ ] 「检查更新」发现新版 → 下载 → 校验通过 → 唤起安装器（拒绝路径由单元测试覆盖，本项验证正向链路）
